Selectores de reglas css

Selector: * { }

Este selector es el universal. Los estilos se aplican a todo el html.

Selector: <div>

Este selector es el de etiqueta. Los estilos se aplican a todas las etiquetas <div>.

Selector: #id

Este selector es de id. Los estilos se aplican a la etiqueta con id="selector-id"

Selector: .class

Este selector de clase. Los estilos se aplican a todas las etiquetas que comparten class="selector-class"

Selector: [input:text]

Este selector es de atributo. Los estilos se aplican a todas las etiquetas que contengan el atributo div[aria-readonly="false"]
